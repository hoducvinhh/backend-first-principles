# Backend Security Notes

A curated collection of notes, architectural principles, and deep dives into securing backend applications.

## 📌 Topics Covered
- **Cryptography Fundamentals**: Symmetric, Asymmetric, Hashing, Signatures
- **Authentication & Authorization**: OAuth2, OIDC, JWT, RBAC, ABAC
- **API & Application Security**: OWASP Top 10, Common Vulnerabilities & Mitigations
- **Infrastructure & Transport**: TLS/SSL, Reverse Proxy Hardening, Secrets Management
- **Auditing & Defensive Coding**: Input validation, sanitize sinks, rate limiting, logging
